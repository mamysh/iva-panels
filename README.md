# iva-panels

Интерактивные панели для плагинов Ивы в Telegram: переходы по кнопкам обновляют одно сообщение, а состояние экрана сохраняется между перезапусками.

**Статус: экспериментальная разработка, 0.1.0-dev.2.** Репозиторий пока приватный. Пройден изолированный маршрут штатных модулей Bridge до собранного сервиса с синтетическим Telegram. Ручные нажатия и рабочая установка ещё не проверены; версия не рекомендована для рабочей установки. Выпуск и установка проверяются отдельно.

## Что уже работает

Команда `/panels` открывает список известных включённых и доверенных интеграций. Сейчас поддержаны карточки регистрации Bitrix24 и отправки файлов: включение, доверие и commit из локального реестра Ивы. Кнопки «Обновить сведения», «К плагинам» и «Закрыть» меняют исходное сообщение.

Карточка показывает регистрацию плагина. Доступ к порталу, токенам, задачам и настройки интеграций эта версия не проверяет и не меняет. Если ответ Telegram на первоначальную отправку потерян, повторное событие не создаёт ещё одно сообщение; пользователь может открыть новую панель командой.

## Для чего развивать дальше

Общие панели могут пригодиться для настроек, списков, карточек и пошаговых форм разных интеграций. Поэтому название шире меню. Будущие адаптеры должны предоставлять собственные данные и соблюдать права своего плагина. Универсального подключения сторонних плагинов и операций записи в этой версии нет.

## Начать знакомство

Для разработки нужен Node.js 24:

```sh
npm ci
npm run check
```

Поставляемый сервис уже содержит зависимости в `server.mjs`. Для исследовательского запуска и требований к закрытой конфигурации см. [SETUP](docs/SETUP.md). Переключение рабочего Bridge требует отдельной проверки совместимости и явного решения владельца установки.
