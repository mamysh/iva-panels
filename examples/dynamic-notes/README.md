# Настройки заметок: пример подключения

Независимый синтетический плагин для [Panels v2](../../docs/DYNAMIC_API.md).
Меняет одну локальную настройку «Компактный вид». Node.js 24, без npm-зависимостей.
Внешних бизнес-записей и Telegram credentials нет.

| Файл                                          | Назначение                                                    |
| --------------------------------------------- | ------------------------------------------------------------- |
| `plugin.json`                                 | Штатный manifest Ивы.                                         |
| `panels.json`                                 | Объявление v2 API.                                            |
| `sh.iva/services/panels/service.json`         | Запуск службы менеджером Ивы.                                 |
| `sh.iva/services/panels/server.mjs`           | Собственная схема настройки, экран и предложение.             |
| `sh.iva/services/panels/settings-service.mjs` | Протокол, атомарное хранение и квитанция локальной настройки. |

## Проверить без установки Ивы

Из корня checkout Panels:

```sh
npm ci
node scripts/check-panel.ts examples/dynamic-notes
node --test test/integration-example.test.ts
```

Тест копирует пакет во временный каталог и запускает его отдельным процессом.
Проверяет read, prepare без эффекта, cancel, confirm, повтор после рестарта
и запрос карточки через настоящий socket Panels. Доставка Telegram синтетическая.

## Сделать свой плагин

1. Измените имя и версию согласованно в manifest, descriptor и `serveSettings`.
2. Определите validate/screen/propose; не помещайте секреты в тексты.
3. Выберите свободный service port по правилам установки Ивы.
4. Для собственного storage реализуйте адаптер к нему вместо второй конфигурации.
5. Сохраните обычные инструменты плагина и работу без Panels.

`PLUGIN_DATA` задаёт штатный менеджер. Сервер создаёт `panels.sock` с 0600
и `panels-settings.json` с настройками, revision, предложением и последней квитанцией.
Helper рассчитан на локальные настройки; для внешних действий нужен собственный
durable job и проверка результата.
