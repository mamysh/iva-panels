# Возможности Panels

## Стабильная версия 0.2.0

Все записи каталога ведут в общую карточку. Карточка показывает состояние включения и доверия, а также связь: отсутствует, несовместима, v1 справка, v2 объявленный API или недоступна до включения/trust. Возможность настройки не считается проверенной по одному descriptor: фактический ответ проверяется при открытии.

При `dynamicPanels: true` плагин с v2 может предоставлять текущие настройки, конечный набор действий, preview/confirm/cancel/status. Действие выполняет сам плагин. Для нового плагина не нужен адаптер в Panels. Bitrix24 0.9.0 предоставляет собственные настройки через v2; files и прежний Bitrix используют «Совместимую панель». V1 и legacy адаптеры сохраняются. Enable/disable остаётся отдельным lifecycle механизмом.

«Подключить к Panels» даёт запрос для Ивы и объяснение текущего состояния. Skill `iva-panels-integration` поставляется с плагином: он описывает подключение существующего и разработку нового плагина. Это подготовка изменений по запросу, без автоматической перезаписи установленных исходников. Полный [контракт и пример](DYNAMIC_API.md). Новый runtime опубликован в приватной рабочей ветке, прошёл Linux CI и установлен; владелец подтвердил работу новых карточек и переходов в Telegram.

## Возможности stable 0.1.0

Карта стабильного выпуска 0.1.0. Возможности сверены с кодом; установка и проверка в Telegram — отдельные этапы. Репозиторий остаётся приватным до выполнения [условий публичного открытия](RELEASING.md).

## Для владельца Ивы

Panels открывается командой `/panels` в личном Telegram-чате разрешённого владельца. Многопользовательского кабинета и отдельных ролей администратора здесь нет.

| Возможность                   | Сейчас                                                                                                                                       | Ограничение                                                                                              |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Список установленных плагинов | Автоматически читает реестр, включая выключенные и недоверенные регистрации; есть обновление и страницы                                      | Это состояние регистрации, а не постоянная проверка работоспособности                                    |
| Карточка нового плагина       | Имя, состояние, версия и описание из корректного manifest                                                                                    | Особые настройки не возникают автоматически                                                              |
| Включение и выключение        | Общие кнопки, показ изменения, подтверждение, проверка результата и последняя задача                                                         | Требуют разрешения оператора, доверенной регистрации и закреплённой версии; сам Panels исключён          |
| Bitrix24: просмотр            | Политика, подключение и права webhook                                                                                                        | Адаптер подключается отдельно                                                                            |
| Bitrix24: настройки           | Чтение или запись с подтверждением; разрешение загрузки и удаления; поля сотрудников: ID, имена, рабочий профиль; email для рабочего профиля | Отдельное разрешение редактора; запись выполняет сам Bitrix-плагин; права webhook на портале не меняются |
| Отправка файлов               | Версия, правила и проверка публичного stable с CI                                                                                            | В версиях 0.3.2/0.3.3 нет редактируемых настроек; проверка обновления не устанавливает его               |
| Навигация                     | Кнопки обновляют одно сообщение; сохраняется состояние экрана                                                                                | Старые кнопки имеют срок действия и проверку адресата/ревизии                                            |

Переключение плагина может потребовать полной сборки и перезапуска Ивы. Panels использует неизменённый штатный менеджер с полной сборкой той же версии ядра и проверяет результат. При неизвестном исходе следующая команда блокируется до проверки оператора; автоматического повторения или отката всего реестра нет. Совместимость управления закреплена за проверенной версией менеджера, а не обещана для любого будущего ядра.

Выключение file-delivery прекращает его инструменты после завершения сборки. Встроенный `send_file` ядра остаётся независимым: это не общий запрет отправки вложений.

Через Panels пока нельзя установить, обновить или удалить плагин, выдать ему доверие, редактировать произвольные секреты, просмотреть все журналы или постоянно контролировать все службы. Это также не интерфейс для бизнес-операций Битрикса: панели не создают задачи и не загружают бизнес-файлы.

## Для разработчика плагина

| Подключение                                                            | Что получает автор                                                                             |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Обычная корректная регистрация в Иве                                   | Автоматическое появление в каталоге и базовая карточка без изменений Panels                    |
| Доверенная закреплённая установка с поддержкой штатного enable/disable | Общие кнопки управления при разрешении оператора; отдельный descriptor не нужен                |
| `panels.json` рядом с `plugin.json`                                    | Собственные информационные страницы и переходы в общем интерфейсе без отдельного Telegram-бота |

Контракт `iva-panels/v1` подходит для справки, описания возможностей, инструкции подключения и пояснений к режимам. Он декларативный: тексты и страницы статические, кнопки переходят между ними. Общий renderer и engine обеспечивают навигацию, сохранение экрана и проверки кнопок.

Имя и версия должны совпадать с manifest. Доступны JSON Schema, пример и CLI-проверка; ограничения и точная форма описаны в [PLUGIN_API](PLUGIN_API.md). Ошибочное описание оставляет базовую карточку доступной.

**Общего API динамических настроек пока нет.** `panels.json` не подключает чтение актуальной конфигурации, запись значений, команды, shell или произвольные MCP endpoints. Редактор Битрикса — встроенный адаптер, а не функция, которую новый плагин получает только добавлением descriptor. Для собственного редактора сегодня требуется отдельная интеграция адаптера в Panels.

Следующий этап общего контракта должен определить чтение состояния и полей, подготовку изменения, показ пользователю, подтверждение/отмену, ревизии, сроки и проверку неизвестного результата. Бизнес-правила, проверка прав и сохранение остаются у конкретного плагина. Это направление разработки, а не реализованный SDK.

## Что проверено

Автоматические проверки охватывают каталог, descriptor, навигацию, штатный Bridge, редактор Bitrix24 и управление через закреплённый менеджер. Владелец ранее подтвердил переходы в одном сообщении, rich-меню и обычный ответ Ивы. Операторский цикл dev.11 проверен отдельно. Для dev.13 на Иве 0.4.14 владелец подтвердил отмену, выключение и обратное включение файлового плагина, сохранение Битрикса и обычный ответ Ивы; серверная сверка подтвердила done, включённые плагины и работающие службы. Полная матрица аварий не проверена. Точные границы — в [COMPATIBILITY](COMPATIBILITY.md).
