# Возможности и ограничения

Стабильная 0.2.0 предоставляет каталог и общий API. Карточки действий прямо в чате
добавлены в 0.3 RC. [Каналы и совместимость](COMPATIBILITY.md).

## Пользователю

| Возможность             | Условия                                                    | Граница                                                       |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| Каталог                 | Плагин зарегистрирован в Иве                               | Показывает регистрацию, не непрерывный health служб.          |
| Базовая карточка        | Корректный manifest                                        | Доступна и для выключенных/недоверенных плагинов.             |
| Справка и переходы v1   | Включённый, доверенный плагин с `panels.json`              | Статический текст, без записи и исполнения команд.            |
| Настройки и действия v2 | `dynamicPanels: true`, descriptor и работающий API плагина | Набор полей и действий определяет плагин.                     |
| Карточка в разговоре    | 0.3 RC, v2, `mode: panels`, один owner                     | Карточка отправляется в личный чат настроенного владельца.    |
| Навигация               | Действующий экран                                          | Одно сообщение, проверка пользователя, чата, ревизии и срока. |
| Enable/disable          | Отдельный opt-in и поддерживаемый exact менеджер           | Только 0.4.12/0.4.14; на 0.5.7 не поддерживается.             |

## Совместимые интеграции

**Bitrix24.** Стабильная 0.9.0 предоставляет настройки через общий v2 API.
Прежний адаптер настроек и диагностики оставлен для совместимости и включается
отдельно. Кадровые карточки в разговоре требуют Bitrix24 0.10.0-rc.4 и Panels 0.3 RC.
Кадровые проверки, очередь, запись и чтение результата принадлежат Bitrix24.

**Отправка файлов.** Совместимая панель знает правила 0.3.2/0.3.3, показывает версию
и проверяет публичный stable с CI. Она не читает содержимое вложений, не выполняет
доставку и не устанавливает обновление. Выключение file-delivery не отключает
независимый встроенный `send_file` ядра.

## Автору плагина

Для собственного v2 не нужен адаптер или правка исходников Panels. Нужны descriptor
и сервер протокола; можно встроить его в существующую службу. [Руководство](INTEGRATION.md)
содержит рабочий пакет, helper локальных настроек и критерии проверки.

API не создаёт интеграцию автоматически: произвольный сторонний плагин должен
реализовать контракт. При доступных исходниках Ива может подготовить доработку
с поставляемым skill. Без исходников потребуется API или участие автора.

Panels не предоставляет произвольный редактор секретов, установку/обновление/
удаление/trust, журнал всех служб или многопользовательские административные роли.
Плагин остаётся работоспособным без Panels и сохраняет собственные инструменты.

## Ошибки и восстановление

Prepare показывает предложение без эффекта. Отмена не меняет настройки.
Confirm вызывает плагин только после проверки сохранённого экрана. При неизвестном
исходе Panels блокирует новые изменения и читает status; автоматически повторять
операцию или восстанавливать реестр из старого снимка нельзя.

Полная матрица аварийного восстановления и установка на чистую Иву пока не приняты.
[Точные границы проверок](COMPATIBILITY.md), [помощь](FAQ.md).
