# Совместимость и доказательства

Состояние на 7 октября 2026 года: локальный прототип `0.1.0-dev.1`. Проверенная серверная установка отсутствует. Номер версии не является обещанием совместимости.

| Граница                  | Что подтверждено                                                                                | Что ещё требуется                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Node.js 24               | TypeScript, unit tests, собранный сервис                                                        | Linux launcher и полный lifecycle менеджера служб              |
| Экран и квитанции        | Повторы, restart, потерянный send, retry edit, stale/owner/chat/message/TTL, повреждённый state | Отказ диска и процессы при аварийном завершении                |
| HTTP router              | handled receipt, forwarding body/headers, compressed response, secret/owner checks, passthrough | Штатный Bridge целиком, очередь, busy-agent и retry acceptance |
| Iva 0.4.11               | Исследованы Bridge transform и queue schema, транспортная локальная проба                       | End-to-end проверка exact SHA установленного ядра              |
| Iva 0.4.12               | Кандидат для следующей проверки                                                                 | Полный маршрут; не объявляется поддержанным                    |
| Telegram                 | Bot API delivery adapter и синтетические ответы в тестах                                        | Тестовый бот и ручное нажатие кнопок                           |
| Bitrix24 / file-delivery | Только карточки локальной регистрации                                                           | Реальные read-only адаптеры и независимые потребители          |

Проба контракта Bridge отдельно от этого репозитория не заменяет end-to-end тест поставляемого плагина. При обновлении ядра повторно проверяйте преобразование callbacks, message ID, acceptance headers, очередь и адрес назначения Bridge. Никакие бизнес-записи не проверялись и не поддерживаются.
