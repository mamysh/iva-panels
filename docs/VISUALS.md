# Иллюстрации

`assets/panels-hero.svg` — оригинальная векторная схема для главной: каталог,
настройка и отдельное подтверждение. Это иллюстрация, не скриншот Telegram.
Текст и названия синтетические. Файл не содержит внешних ресурсов или скриптов.

Палитра согласована с плагином Bitrix24: фон `#080B0A`, текст `#F3F5EF`,
мята `#91C9AD`, голубой `#95BFDA`, коралл `#E8A88D`. Ветка ивы связывает
изображение с Ивой; карточки показывают последовательность выбора.

Сохраняйте SVG как исходник. Проверяйте читаемость на GitHub при ширине
главной страницы и на узком экране. Важные условия, команды и примеры
дублируются обычным Markdown и доступны без картинки.

Лицензия MIT, как у репозитория. AI-генерация растровых изображений не использовалась.
