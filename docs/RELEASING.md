# Выпуск и публичное открытие

## Разные действия

Изменение исходников в приватном репозитории, release/tag, установка на Иву
и открытие репозитория — самостоятельные действия. Выпуск кандидата не переводит
`stable` или Latest. Открытие public выполняется только по отдельному явному
решению владельца после просмотра конкретного итогового комплекта.

Текущий stable — **0.2.0**; кандидат — **0.3.0-rc.5**.
Обновление существующей Ивы не является приёмкой чистой установки.

## Перед выпуском

- Согласованы package/lock, manifest, runtime version, README, CHANGELOG и release notes.
- Чистый checkout: `npm ci`, `npm run check`, проверки примеров, launcher syntax и local links.
- Committed bundles воспроизводимы; dependency audit рассмотрен, нет необъяснённых ошибок.
- CI завершился на exact SHA; `stable` и immutable tag при выпуске указывают на выбранный проверенный commit.
- Подтверждены заявленные версии Bridge и менеджера; неизвестная версия не разрешена по одному номеру.
- Выполнена применимая [приёмка чистой установки](ACCEPTANCE.md), включая возврат маршрута и данные.
- Пользовательские инструкции, skill, API/schema/helper и примеры совпадают с поведением.
- Установка на рабочую Иву имеет отдельное разрешение, резерв и послеоперационную проверку.

Release notes объясняют пользу, обновление закреплённого источника, новые права,
миграцию и существенные ограничения. Не превращайте их во внутренний журнал работ.

## Перед открытием public

- Владелец просмотрел результат и явно разрешил открытие.
- Проверены все reachable refs и Git-объекты, включая ранние commits, ветки и tags;
  отдельно проверены PR/issue тексты, release notes, assets, workflow artifacts/logs и метаданные GitHub.
- Нет секретов, webhook, персональных данных, локальной памяти и приватных путей.
  Обнаруженный настоящий секрет отозван; удаления файла недостаточно.
- Чистый clone содержит всё нужное внешнему пользователю и разработчику.
- README, пользовательские руководства и синтетические иллюстрации проверены в браузере.
- About, homepage/topics, MIT, помощь и приватное сообщение об уязвимости готовы.
- Нет незакрытых обязательных проверок совместимости, установки, возврата маршрута и восстановления.

`check:privacy` дополняет ручной аудит, а не заменяет его. Оно проверяет файлы
поставки и доступные локальные Git-объекты; не видит неполученные refs,
GitHub assets, содержимое чужих сервисов и секреты неизвестного формата.

29 октября 2026 владелец явно разрешил открыть репозиторий после обновления
описания, до разработки установщика0.4 RC. Это решение разрешает публичный
доступ к исходникам кандидата при явно указанных незавершённых приёмках;
оно не объявляет stable0.3/0.4 и не заменяет испытание чистой установки.
Прежнее правило «все приёмки до public» для этого открытия заменено данным решением.
Перед будущим stable обязательные приёмки сохраняются.
