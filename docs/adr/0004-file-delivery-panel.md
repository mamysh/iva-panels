# ADR 0004: сведения о доставке и независимая проверка stable

Статус: принято, эксперимент dev.6.

## Причина

У file-delivery 0.3.2 нет пользовательского settings API. Его updater check меняет глобальное предложение установки, которое может уже использовать разговорное меню. Панелям нужны полезные сведения и проверка доступной версии без замены этого предложения.

## Решение

Локальные страницы показывают manifest/commit и правила известного выпуска. По отдельному нажатию панели выполняют ограниченные GET фиксированного публичного репозитория: stable SHA, manifest по SHA и последний push CI ci.yml по тому же SHA. Дочерний updater не запускается, plugin-data/offer не читается и не пишется. Установка остаётся штатным разговорным updater с прежним подтверждением.

## Последствия

Нет новых секретов или полномочий на файлы. Появляются явные внешние GET, network failures/rate limits и зависимость от публичного API. Проверка stable не обещает обновление закреплённого источника. Правила другой версии требуют проверки и нового профиля; интерфейс не придумывает редактируемые настройки. Полученный CI — снимок, а не полномочие устанавливать код.
