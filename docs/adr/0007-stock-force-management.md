# 0007 — Полная штатная сборка и проверка соседних плагинов

Статус: принято для dev.10. Дополняет ADR0006.

## Решение

Ядро не изменяем. На stock0.4.12 reuse prepared tree ошибочно исключает MCP-only соседей. Panels использует неизменённый createPluginCommands с buildVersion callback: штатный runVersionUpdate(force=true,requirePlugins=true) на текущем commit и native update-finish. Проверяются source hashes поддержанного менеджера. Будущий неизвестный manager получает отказ до эффекта.

Preview/confirm/worker фиксируют весь реестр. Done означает только target.enabled изменён; остальные регистрации, необходимые артефакты, назначенные службы и userbot проверены. Неожиданное изменение даёт uncertain и имена, блокирует новые задачи до операторской сверки. Нет автоматического повтора или отката чужих данных.

## Последствия

Переключение code/MCP требует новой сборки и занимает больше времени. История версий и штатный current меняются; исходники, core commit, выбранная ветка и remote остаются прежними. Прямые команды Ивы вне Panels сохраняют upstream bug. Внешнее администрирование не защищено CAS; постпроверка обнаруживает расхождение.

Settings остаются в адаптерах интеграций: Bitrix24 поддержан, descriptor v1 предоставляет только страницы чтения. Автоматическое обнаружение нового плагина не означает наличие редактора произвольных настроек.
