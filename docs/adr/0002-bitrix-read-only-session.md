# ADR 0002: read-only Bitrix24 через отдельную stdio-сессию

Дата: 2026-10-07. Статус: принято.

Нужно показывать фактические настройки и права Bitrix24, включая defaults при отсутствии settings.json. Прямое чтение файла не воспроизводит defaults плагина. Общий штатный MCP proxy имеет одну сессию: новый initialize сбрасывает сессию Eve.

Выбран явно включаемый адаптер с собственным кратковременным stdio client к установленному enabled/trusted Bitrix24 0.9.0-rc.1. Вызовы ограничены settings actions/privacy и connection/capabilities; reply и изменения не передаются. Ответы проектируются на известные поля, навигацию строят панели. Ядро и код Bitrix24 не меняются.

Цена решения — доступ панелей к scoped webhook, дополнительные процессы и диагностические запросы, зависимость от внутреннего размещения Ивы и контракта выбранного Bitrix24. Поэтому адаптер по умолчанию выключен; широкое подключение чужих MCP-инструментов не является частью API. Изменения политики требуют следующего решения и прежнего подтверждения владельцем.
