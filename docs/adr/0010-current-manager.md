# 0010 — Штатный менеджер Ивы 0.5.7

Статус: реализовано в кандидате 0.3.0-rc.4; серверная приёмка отдельно.
Дополняет [ADR0007](0007-stock-force-management.md).

## Причина

Ива 0.5.7 имеет штатные enable/disable. Panels до rc.4 отклонял её собственной
проверкой совместимости, закреплённой за 0.4.12/0.4.14. Bridge и общий API
на 0.5.7 проверялись отдельно и не доказывали работу управления.

## Решение

Поддержать только exact `0.5.7-ae313753a1ae`. Проверять SHA-256 десяти исходников:
dispatcher, plugin-cli-context, plugin-cli-trust, runtime, plugin-core,
version-update, version-store, plugin-build, plugin-units и update-finish.
Изменённый модуль, другой commit или несовпадение CLI с `current` запрещают команду.
Это проверка поддержанной реализации, не аттестация всего ядра от вредоносного владельца.

На неизменённой 0.5.7 синтетическая регрессия воспроизводит выключение
MCP-only соседа при reuse подготовленного дерева: проверка carried plugins
не устраняет фильтрацию mounted по extension mount. Это не рабочий инцидент;
в тесте сравниваются штатный reuse и принудительная сборка.

Сохранить штатные команды с полной сборкой того же commit и `requirePlugins=true`
для всех оставшихся включённых плагинов. Ядро, ветка обновлений и remote не меняются.
Полный снимок реестра, артефакты, службы и userbot проверяются до/после операции.
Неизвестный исход остаётся uncertain без повтора и автоматической обратной команды.

## Проверка

CI использует неизменённый exact upstream. Проверяются native cancel/disable/enable,
повторы и отказ сборки, неизменность метаданных соседей и их артефактов,
каждый source pin, пути units через current после удаления прежней версии.
Сборка, systemd и health в этой матрице синтетические; работающий сервер,
первичная установка и ручные Telegram-нажатия принимаются отдельно.

Поддержка является свойством установленного rc.4, а не обновлённой документации.
Новые версии Ивы не допускаются автоматически без отдельной проверки.
