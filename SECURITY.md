# Безопасность

Сервис имеет доступ к Telegram Bot API токену и принимает трафик Bridge. Это доверенный локальный компонент с существенными полномочиями. Он слушает только IPv4 loopback; не публикуйте его порт через внешний reverse proxy. Ограничьте доступ к машине и приватному каталогу данных.

## Граница текущей версии

Панели только читают разрешённые поля реестра установленных плагинов. Сервис не читает vault, настройки Bitrix24, содержимое задач или файлы доставки. Он не выполняет бизнес-операции и не предоставляет инструментов модели.

Для собственного входящего события проверяются общий секрет Bridge, разрешённый пользователь, личный чат и отсутствие признака бота. Кнопка дополнительно связана с владельцем, чатом, сообщением, ревизией и сроком экрана. Текст преобразованного события не является независимым доказательством ручного нажатия: обладатель общего секрета может его подделать. Эти проверки недостаточны для разрешения чувствительных операций записи.

Остальные запросы передаются исходному Eve по фиксированному loopback origin, включая заголовки аутентификации. Перехват всей цепочки означает, что отказ сервиса может нарушить работу Bridge. До подключения нужен проверенный возврат к исходному маршруту.

## Хранение и ошибки

`config.json` требует права 0600; секрет и Bot API токен задаются явно оператором. Они не попадают в журналы. `screens.json` содержит идентификаторы владельца, чата, сообщения, представления, сроки и хеши событий; он записывается атомарно с правами 0600. Это приватные пользовательские данные. Полные входящие сообщения не сохраняются. Каталог данных должен принадлежать выделенному пользователю и иметь права 0700.

Повреждённое состояние останавливает запуск. Не удаляйте его автоматически: это может сбросить защиту от повторов. Нет миграции формата или автоматического удаления данных после деинсталляции. Оператор управляет резервами и удалением.

Неоднозначная первоначальная отправка не повторяется. Редактирование повторяет только сохранённое представление. Если сообщение удалено или Bot API постоянно отказывает, доставка может остаться незавершённой и блокировать этот экран; открытие новой панели и диагностика предпочтительнее ручной правки состояния.

## Сообщение об уязвимости

До открытия репозитория сообщайте владельцу через согласованный приватный канал. Не отправляйте токены, идентификаторы чатов или реальные данные в GitHub issues. Перед публичным открытием владелец должен включить приватные сообщения об уязвимостях и проверить этот процесс.
