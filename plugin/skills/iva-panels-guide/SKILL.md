# Поручение и подтверждение в чате

Помоги пользователю получить результат в текущем разговоре. Для изменения настроек
можно открыть `/panels ИМЯ_ПЛАГИНА`; обычный `/panels` показывает список.
Нажатие названия открывает возможности, «О плагине» — сведения и управление.
Справка `/panels` объясняет, где что находится. Не ищи веб-сайт Panels или публичный URL.

- Сначала определи **текущее** поручение. При событии от кнопки отвечай на действие
  и сообщение, к которому она относится. Не повторяй несвязанную кадровую заявку
  или прежний апрув из истории. Результат чужой старой операции не является
  разрешением на новое действие.
- «В задачи» сохраняет пункт в обычный список Ивы через её tasks. Скажи кратко,
  что именно сохранено и что осталось сделать. Не называй это очередью Panels,
  не создавай второй список и не выдавай сохранение за отправку сообщения.
- Если пользователь просит выполнить действие, используй существующие инструменты
  целевого плагина. Поддерживаемый плагин сам готовит предложение и показывает
  карточку подтверждения прямо в чате. Не отправляй искать апрув через каталог.
- Доставка карточки, постановка в очередь и успешное выполнение — разные состояния.
  Сообщай подтверждённый результат инструмента. При неизвестном исходе читай status,
  не повторяй действие ради получения ответа. Не превращай текст «ок» в callback.
- Не обещай действия, которых нет в инструментах (например, увольнение, если плагин
  умеет только приглашать и менять профиль). Объясни ограничение конкретно.
- Если операция не поддерживает карточки Panels, следуй её собственному контракту
  согласования. Не выдумывай кнопку или единый механизм согласия для всех инструментов.
- Подключение API — отдельная разработка. Загрузи `iva-panels-integration`, выясни
  целевой плагин и проверь inspect.mjs. Самому iva-panels второй API не нужен.

Этот skill не перехватывает штатные кнопки Ивы и не меняет её tasks, память или ядро.
Он применяется после загрузки; исправление контекста ядра не заявляется.

## Первая установка0.4 RC и восстановление

До установки следуй INSTALL.md выбранного пакета и используй штатный plugin propose.
После установки диагностика доступна без npm:

```sh
node "$IVA_DATA_DIR/custom/plugins/iva-panels/sh.iva/services/router/install.mjs" status
```

Если IVA_DATA_DIR не задан, сначала выясни фактический каталог данных штатным способом.
Не выводи.env или токены. Connected означает проверенное соединение, presented —
доставленную начальную карточку. Unknown delivery не разрешает повтор отправки:
пользователь может открыть /panels. Rolled_back означает возврат прежнего маршрута;
retry выполняется только по новому запросу владельца. Uncertain требует сверки
оператора: не стирай journal/config/drop-in и не повторяй подключение вслепую.
Manual_or_not_configured не разрешает заменять существующую ручную настройку.
