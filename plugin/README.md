# Panels для Ивы

Каталог плагинов, настройки и карточки подтверждения в личном Telegram-чате.

В0.4 RC после штатного подтверждения установки служба на совместимой Иве0.5.7
создаёт приватный config из локальных настроек и подключает Telegram Bridge
через собственный user drop-in. Потребуется перезапуск только Bridge.
Перед переключением создаётся отдельный таймер возврата прежнего маршрута.

Плагин получает доступ к существующему токену Telegram и секрету локального Bridge.
Секреты не нужно отправлять в чат. Ядро, его исходники, обычные задачи и другие
плагины не меняются. Вторая служба polling не создаётся.

Существующий config не перезаписывается. Неизвестные версии, несколько владельцев
и нестандартные маршруты требуют отдельной проверки. Кандидат не заменяет приёмку
на новой Иве и настоящем Telegram.
